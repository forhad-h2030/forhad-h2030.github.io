SpinQuest Signal and Background Classifier

A multi-stage deep-learning pipeline that separates J/ψ, ψ′, Drell–Yan, and combinatoric events to create clean signal samples for transverse single-spin asymmetry analysis.

Architecture

Three-stage classification pipeline

The workflow combines specialized binary classifiers, Real NVP–style normalizing-flow tuning of the simulated events, and a final four-fold multiclass network so each event receives physics-ready class probabilities.

1

Binary DNNs

Sequential models isolate J/ψ, ψ′, and Drell–Yan signals from the remaining background.

2

Flow tuning

A Real NVP–style normalizing flow tunes simulated combinatoric-background events to match the classifier-tagged experimental data.

3

Multiclass DNN

A four-fold softmax model produces simultaneous per-event probabilities for TSSA extraction.

Stage 1

Specialized binary classifiers

Three binary DNNs are trained sequentially, each targeting one signal class against all other events. Their tagged probability scores are written back into experimental ROOT files with tag_exp_root_with_ml.py and are used to tune the simulated combinatoric-background events to match the classifier-tagged experimental data through a Real NVP–style normalizing flow.

Stage 2

Four-fold multiclass classifier

The four-class softmax network takes the flow-tuned simulated events and works as a four-fold classifier, returning simultaneous per-event probabilities for J/ψ, ψ′, Drell–Yan, and combinatoric background, the classification used for transverse single-spin asymmetry (TSSA) extraction.

Data workflow

ROOT preprocessing and training

Raw ROOT data is transformed into NumPy training arrays containing invariant mass, transverse momentum, rapidity, and individual-muon momentum features. Event selection applies vertex-position cuts and score thresholds from earlier stages.
