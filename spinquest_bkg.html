SpinQuest Signal and Background Classifier

A multi-stage deep learning pipeline for dimuon event classification in the SpinQuest (E1039) experiment at Fermilab. The goal is to separate four event categories — J/ψ, ψ′, Drell–Yan, and combinatoric background — from raw experimental data, providing clean signal samples for transverse single-spin asymmetry (TSSA) extraction. The pipeline combines iterative binary classifiers with MC simulation tuning and a final multiclass softmax DNN.

Pipeline Overview

Stage 1 — Binary DNN Classifiers

Three binary deep neural networks are trained sequentially, each targeting one signal class against all others:

  • J/ψ classifier — separates J/ψ events from non-J/ψ background
  • ψ′ classifier — separates ψ(2S) events from remaining background
  • Drell–Yan classifier — separates Drell–Yan events from combinatoric background

Each classifier outputs a per-event probability score. These scores are written back into the experimental ROOT files via tag_exp_root_with_ml.py, making them available as features for downstream stages.

Stage 2 — MC Simulation Tuning

The combinatoric background MC must be tuned to match the distributions of the classifier input features — including kinematic and momentum variables — of classified experimental background before it can be used for training (see the data/ directory in the repository for the full feature set). This tuning is handled by the SpinQuest Agentic MC Tuner — an LLM-driven pipeline using normalizing flow rejection sampling and BDT mass reweighting to bring the MC into agreement with data.

Stage 3 — Multiclass Softmax DNN

A final 4-class softmax DNN performs simultaneous classification across all event types (J/ψ, ψ′, Drell–Yan, combinatoric background), using the binary classifier scores and kinematic features as input. This provides per-event class probabilities used directly in the TSSA analysis.

Data & Preprocessing

Raw data is stored in ROOT format. The preprocessing pipeline (preprocess/) extracts dimuon kinematic features — invariant mass, transverse momentum, rapidity, and individual muon momenta — into NumPy arrays for training. Event selection applies vertex position cuts and ML score thresholds from earlier classifier stages.
